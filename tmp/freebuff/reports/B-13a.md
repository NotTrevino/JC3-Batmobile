tool `Tools/scripts/stringlookup_compare.py BEFORE AFTER` now also prints `preexisting strings equal`,
`SortedPairs ascending` and `dialogue lines equal`. Test files live in `E:/Modding/_JC3grab/strings_rt/`

Method: `Text` is the last array in the data block, so the new strings are appended to it in place
(old TextOffsets unchanged). Each language that gains a pair gets a new SortedPairs array after `Text`
with the pair at its ascending position, and its header is repointed. The four trailing tables (instance,
type, string-hash, name; no data offsets in them) move by one 16-aligned delta. The header offsets,
the instance size and the total size are fixed up.
