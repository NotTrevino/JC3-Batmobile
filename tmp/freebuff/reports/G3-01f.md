## 2. The branch-word encoding — split verdict (both new)

* `EX_Skip` (`0x18`): `word = (target − (at+3)) + 4 × references skipped`; equivalently the word is a
  distance in a stream where a reference token weighs **9** bytes, not 5. Exact for all five skips here
  (18@→21, 40@→43, 259 word 13→271, 271 word 39→301, 324 word 11→334) and for all 12 skips in the 35
  walkable `Startup.upk` functions that carry one.
* `EX_Jump` / `EX_JumpIfNot` (`0x06`/`0x07`): **not** positions. Tested 11 bases (`abs`, ±22 payload,
  `pos+word`, `pos+3+word`, `pos−word`, `L−word`, `L−word−3`, and three weight-expanded spaces) against
  this walk's own 135 token starts: no base resolves the six words; the best (`rel_pos`) gets 2 of 6, and
  those two are the short words 49 and 81 (chance: ≤12 of 57 corpus words for every base). A prefix-sum
  weight model is impossible: span 248→309 implies 4.6 bytes per reference, span 309→342 implies 2.5.
  What *is* decoded: equal targets share a word (309/312 both 474; selector 59/62 both 125, 116/119 both
  206) and the words rise with the target — a coordinate this script cannot reconstruct.

   walk's 135 token starts, the same 11 over 57 corpus jump words, and a solved prefix-sum weight model.
   Nothing closes; equal words for equal targets and monotonicity show the words are a coordinate.
   Would be found in: a token/opcode table for this build, or an uncooked (editor) script of the same
   function. Consequence: the CFG's two `Jump` edges and four false-branch edges are marked UNKNOWN.
2. **`0x82` = `&&` or `||`, and `0x9B`/`0x77` = `==` or `!=`.** Extents are proven (walk + skip words);
   semantics are not. `0x81` = negation is *derived* only, from `RPlayerController.ShowHealthBarIfNotMax`
   (export 98240) where the function's name states the negation.
3. **Which caller produced a given runtime transition.** The sampler logs the value, not the caller;
   `DriverLeft` and `OnSleepRBPhysics` can both pass 1.
4. **The owning classes' property-tag lists.** `upk_read.best_walk` returns 0 tags (`end` at byte 0) for
   `BmGame.upk` 10922 `RVehicleBatmobileBase`, 48393 `RBatmobileWinch` and `Engine.upk` 11159 `SVehicle`,
   so the class tag stream format for Class exports is not decoded here; the member verdict uses the
