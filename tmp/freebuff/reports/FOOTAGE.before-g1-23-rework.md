## 2. The Vulcan: no per-second heat is configured

`RBatmobileCannon.HeatUpPerSecond` = **0** in the cannon objects - that is the
per-*second* term, and 0 removes it: nothing here adds heat with time. An overheat path is
still wired - `OverheatOffValue` **0.25**, a `ChainGunOverheatSound` reference
(-148), and the HUD bar (`HeatBarStart` [0.79, 0.68], `HeatBarSize` [0.125, 0.03]) - which is why the
observed *"it never overheats, it fires forever"* (your 2026-10-26 note) is compatible
with this object. It is **not** proof that no other heat input exists: a per-shot add in
native code is not excluded by the grab, so the mechanism is **UNKNOWN** and the
observation stays yours.
