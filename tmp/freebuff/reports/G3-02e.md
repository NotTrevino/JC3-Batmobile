## UNKNOWNs (with what was tried)

1. **The field name at `[Mesh + 0xd8]`.** The chain `[this+0x38c] = Mesh` is proven, but no
   property at `+0xd8` exists for `Pawn`, `Actor`, `ActorComponent`, `PrimitiveComponent` or any
   other class reachable from `RVehicleBatmobileBase`. The two comparisons prove a float is tested
   against `+-0.707`; they do not prove whether it is a pitch, a direction component or a dot
   product.
2. **Who sets bit `0x8000` (`bBattleModeLocked`).** No immediate write exists in `.text`; the
   wholesale and computed writes are listed with the register they source, but resolving which
   one carries bit 15 needs a full dataflow analysis, not done here.
3. **The computed-write masks.** For `or/and [r+0x11d8], reg` the tool reports the last `mov reg,
   imm` within 30 instructions in the same function; where no such load exists (`or ..., eax`
   after a load from memory) the mask is UNKNOWN rather than guessed.
4. **The script side of exit/eject.** The executable proves there is no native route from the
   input handler; the actual input binding and the script function that calls these execs are in
   unrealscript (`BmGame.upk`), which this card does not decode.
