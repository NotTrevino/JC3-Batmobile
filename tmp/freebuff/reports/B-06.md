   `patch`), so their private copies are **tune-only**. The models, sounds and effects their holder

   `unchanged_members` with the reason).
2. **`w618` has no T-11 numeric edit**, so it names the shared shipped tune and is not copied (R7):

3. **Inner ADF instance names.** Each copy's instance is still named `<shipped basename>.wtune`
   (`w602_mediumtank_canon.wtune`, `w603_mediumtank_mgun.wtune`; all 34 shipped tunes are named
   `<basename>.wtune`, i.e. the compiler's record of the source file). The card says "rename internal
   hashes": renaming this one needs a re-encode that is not byte-identical, and the `.epe` resolves a
   tune by **path**. Whether the instance name is load-bearing is **UNKNOWN** — no file in the
   read-only corpus answers it (R4), so nothing was invented.
4. **Loose build.** `Builds/bm-006` is a raw `aaf/` tree like `bm-005`: no `.ee`/`.toc` re-pack, so the
   loose-`.epe` (+ loose `.wtunec`) install path is still unproven offline. B-05's limit, unchanged
   here.
5. **The tune's effect rows** still carry B-05's APC `50calImpact` / `sound_turret_rotation_yaw`
   values. The weapon *effects* are the T-FX10/11/14/15 rows B-08 recorded as `next`; this card does
