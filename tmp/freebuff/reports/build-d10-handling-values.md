## 4. What the read-back actually reads

`verify/d10_readback.json` is produced by taking the built `.ee.toc`, finding the record for each target module, slicing the decompressed `.ee` SARC stream at that record's `(offset, size)`, writing the slice to a temporary `.vmodc` and decoding it with Gibbed ConvertAdf. The `aaf` tree is not consulted - a stale tree would not pass. `t5_build.py`'s own guard (every internal `.toc` record equals its `.ee` member, record list identical to the base) runs inside the build.
