- **0 of 16 claims are backed by `MODES.md`.** The plan's trigger claims rest on `INPUT.md`/`INPUT_D11.md` (keymap absence), `CONTROLS_MENU_SCREENS.md`/`D-11` (LT hold/release, operator-stated), `REBELDROP.md` (menu spawn), `ENTITIES.md` (graph class census) and `mode-switch-carriers.md`/`apply-mode-switch-rows.md` (the two-entity decision). - **Unmodified files.** The plan and `MODES.md` were read only; the output of this check is this file. No game binary, install, GOG folder or save file was opened.
