## UNKNOWNs (with why, and where each would be found)

1. **The master's expression list.** The `Expressions` tag says 237 refs / 952 bytes, but its
   recorded offset (2088) lies past the 2004-byte export, so the tag offsets and `pkg.data()` do
   not share a base. A containment search over the whole 18 MB package image - the count `237`
   followed by 237 u32s that all resolve to `MaterialExpression*` - found **0 candidates**.
   *Where:* the property stream's true base (the decompressed tag stream in `upk_read.walk_tags`),
   not the export slice.
2. **The function bodies.** `DiffuseColor`, `SpecularColor`, `SpecularPower` and `Normal` are null
   expressions with a mask, so the colour is built inside the 12 MaterialFunctions above. Their
   bodies live in `Material_Functions` / `Engine` packages, which this grab never read.
   *Where:* decode `Material_Functions.Batmobile_Damage_Dirt_FCT` (+ Edge/Damage/Mud/Anisotropy)
   the same way as a master material, then follow their inputs to `Material0_BaseColour`.
3. **The emissive branch.** Expression #593 (`MaterialExpressionStaticSwitchParameter`) carries no
   `Value`/`DefaultValue` in its export, so which branch ships is not in the tag stream.
4. **Tonemapper and exposure.** 0 keys in the 37-file config set matched `tonemap` or `exposure`
   (the G3-03 post-process rule *does* search for `Tonemap`/`Exposure`, and the set includes
   `BmEngine.ini`). *Where:* a level's `PostProcessVolume`/`PostProcessChain` package, or a
   `[SystemSettings]` group outside the ini chain that was read.
5. **Reflection / environment.** 0 config keys matched reflection, probe or environment.
   *Where:* the level's environment/probe actor, i.e. a `.upk` in the level packages, not the inis.
6. **A pixel measurement of the body.** No calibrated capture exists: `FOOTAGE.md` measures air time
   from five gameplay clips, not colour, and the project holds no body screenshot with known
   lighting. *Where:* a capture at a named time-of-day/location with the same terms in force, or
   the runtime oracle R-3.

## Notes on method (two defects found and fixed while building this)

- Export indices are package-local. An early cut resolved an expression index with a cross-package
  fallback and silently landed on `MaterialExpressionScalarParameter Ember_Amount` (a fire
  material) instead of the body's static switch. Resolution is now same-package only, and an
  unresolved reference is recorded as missing rather than substituted.
- The parent link is in `objects.jsonl`'s `refs` list, not in the tag stream; reading only tags
  stopped the chain at the body MIC (1 object). The chain is now 3 objects and ends at a `Material`.
