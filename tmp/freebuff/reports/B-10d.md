## 6. UNKNOWNs

- **Chassis box rotation / frame handedness.** COLLISION_GEOM records the box TM as not
  decoded, so the AABB above is exact only if the rotation is identity. It would be settled by
  the `FKBoxElem` layout (G3-06 native layouts), then re-running this script.
- **One box or two.** 169750 carries box 0 (690.305 x 374.536 x 207.5) and box 1
  (679.585 x 345.688 x 103.5 cm, centre z 79.0); this run uses box 0 only. Using box 1 would
  trim 29 cm of width and 104 cm of height - a design decision, not a decoding one.
- **Why T-CO2 ever cited a wheel box.** The ledger row's source text is the only place the
  316 cm constant survives; the reason it was picked is not recorded in any file this run read,
  and it is a ledger-repair question (G3-20d), not a build one.
- **Whether the chassis box is the right collision source at all.** It is the decoded BmAK
  drivable box, but B-10's render-bbox choice was itself made against a Done rule (hull union
  within 5 cm of the body bbox); the two rules now conflict by 25 cm in width and 20 cm in
  height, so a decision is needed before the next build.
