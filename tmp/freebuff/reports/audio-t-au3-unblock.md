### Where in the install the Wwise ids could be found

- **`AkBank` payloads in packages** — the HIRC chunk's Event objects (type `0x04`) are the id table:
  34,497 `AkBank` exports across 2,325 packages; 117 read so far (1,101 event ids). A full sweep is
  the same reader over all of them (this is the route `AUDIO_BANKS2.md` names).
- **Hash-named `.bnk` files** — 15 under `BmGame/CookedPCConsole/SFX/` (`50C63A23.bnk`, `57572DAC.bnk`,
  `EDF036D6.bnk`) and `DLC/<id>/Content/BmGame/CookedPCConsole/SFX/E01EC5A5.bnk`. Name = bank id in
  hex; 14 of the 15 are `BKPK`, a container this toolkit does not parse, so their ids are only
  reachable by a `BKPK` reader.
- **`BKPK` blobs inside `DLG_*` export payloads** — 73 of the 117 read payloads carry one; the id may
  live there.
- **Level packages' `Ww_*` banks** the audio map does not reference — a `Ww_*` bank inside a level
  package is the most likely home for a missing dialogue/sequence id.
- **`AkEvent` objects in `BmGame.upk` / `Startup.upk` / `StartupPatch.upk`** — the name→id pairs the
  map already decodes (`AUDIO_MAP.json` rows: package, outer, event id); new ids would come from the
  same export walk over more packages.
- **Not available:** a Wwise `SoundbanksInfo` manifest is not in the install (checked), so a bank's
  numeric id cannot be mapped to its name from a manifest — only from an `AkBank` payload's `BKHD` id.
