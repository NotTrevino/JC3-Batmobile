### The `Playable_Batmobile_Std_*_SF` coverage question (answered)

`GAPS.md` reports 25–50 %. Its metric is *objects whose tag stream yielded at least one tag*,
so a zero-property class stub counts as undecoded. Recomputing that metric reproduces all
seven published figures exactly (`4/1, 4/2×5, 92/80`), and the byte accounting shows why:

- a 2-byte `0000` payload **is** the property-list terminator — nothing to decode;
- an `ObjectReferencer` whose tag list closes on that same 2-byte terminator, which the
  walker reports as `eof` two bytes short because it needs four bytes to read a tag;
- in `Std_6`, payloads whose tag list closes early and whose remaining bytes are the asset's
  own data (texture mips, material expressions).

Result: **116 exports, 0 undecoded.** The 25–50 % is a counting artifact, not missing data.

### One new structural fact (recorded, not interpreted)

21 relevant `Startup`/`StartupPatch` payloads (component objects, 46 bytes) do not parse from
byte 0 but close a **two-tag** stream from start 12. The 12-byte prefix carries the export
record's own name index at offset 4 on every one of them (`0x64E3` = 25827 =
`FrontCollisionCylinder`, `0xDB8E` = 56206 = `RearCollisionCylinder`) — that is the oracle for
calling the payload a record rather than noise. The tags are stored verbatim in the JSON
(`type`, `offset`, `value`) and are **not** interpreted; no tag *name* is asserted (one
name-table read could not be corroborated, so none is claimed).

## Notes and limitations

- The two Startup packages are chunked with their tables inside the compressed body
  (18,185 B prefix, then chunks). `PartialPackage` decompresses chunk by chunk and stops when
  the needed bytes are inside, so `--write`/`--check` run in ~30 s / ~20 s without holding a
  full multi-GB image.
- `--check` is a full rebuild + byte comparison, so the record cannot silently rot; it also
  asserts the negative results (e.g. `StartupPatch` has no `RVehicleBatmobile` defaults,
  `Showcase_Batmobiles.upk` is an empty level), which will fail loudly if a later read
  contradicts them.
- Nothing in this card changed a game file, a build, or an existing research document.
