2. **A (eject) input byte.** Tried: `RPlayerInput` has `bBatmobileEjectModifier` (786) and no

   property. The modifier byte is decoded; which button it modifies is not in the layout. Same place
   as 1.
3. **Boost duration / boost time field.** Tried: `RBatmobileBooster` has exactly two fields
   (`bBoosting`, `bWarming`); `RVehicleBatmobileBase.GetBoostPct()` is a function
   (`g.cs:3084`); `LastBoostPickupTime` (6580) is a timestamp. No `BoostTimer`/`BoostTime` property
   exists in Generated. Consequence: measure the `bBoosting` transition interval instead of reading a
   timer; `CoolDown`/`InfinitMissilesTime` are weapon timers, not boost.
4. **TArray element stride for `CurrentTargets`/`FiredProjectiles`.** The layout gives the struct
   offset and the declared element type (`BmSDK.TArray<BmSDK.Engine.Actor>`), but not the stride;
   `MarshalUtil.GetSizeUnmanaged<T>` would decide it and is not in the generated tree. Needed only to
   walk the targets (pointer at +2400), not to count them (+2408).

Deliberately **not** claimed: that `bBatmobileEjectModifier` *is* the A button, that
`bReadyGadgetButton` *is* X, and that one cooldown timer rather than the other gates the barrage.
