Q-PILOT step 4: define the card format and write the first cards. A piloting card is one numbered page with: goal, preconditions, exact commands, what the screen must show after each step (a checkable observation), what to do when it does not, and a result line. Write Working/Q/PILOT/CARD_FORMAT.md and the cards LAUNCH.md (backup saves, install via install_v3 Verify, start the game windowed at a fixed size, wait for the main menu), SCREENSHOT.md, RECORD.md (with audio, per the QA-1 lesson), and KILL.md (by PID only). Make each card short enough for DeepSeek: one action per numbered line, no judgement calls. Use pilot-study-universal-modder and pilot-failure-catalogue for the commands and traps.
