# Batmobile — GRAB output

Read-only inventory of the shipped Batman: Arkham Knight Batmobile, generated by `Tools/scripts/batmobile_grab.py` (reader: `upk_read.py`). Every number here is read from the `.upk` files; nothing is hand-listed. Re-run the script to refresh.

## Totals

- packages: **15**
- objects: **20128** (decoded **19203**, native/untagged **925**)
- materials: **185** + **130** instances
- textures: **405**
- meshes: **12**, sockets: **247**
- animation: **253** sequences, **16** sets/trees
- audio: **30** banks, **361** events
- vehicles: **4** RVehicleBatmobile, **4** RVehicleSimBatmobile, **16** wheels

| `AUDIO_MAP.md` | every `AkEvent` → bank → WEM through HIRC, and the banks not on disk (GRB-9) |

| `COCKPIT.json` | the same record, machine source: slot/bone splits, bbox/area per part, ray-cast heights, socket fields, the eye builds and the `--check` counts |

| `MODES.md` | every `BattleMode*` / `TurnOnSpot*` / `Strafe*` / `Transformation*` / `AirControl*` / `Impact*` / `PMDodge*` / `StayUpright*` field the classes declare, its unit and its per-package value — 46 serialised of 107, with the 61 that carry no value in the files stated (G1-21) |
| `MODES.json` | the same record, machine source: offsets, declared types, units, per-package values, ledger coverage and the 29 checks |
| `NATIVE_RELEVANCE.md` | the 925 untagged exports: all 140 over 8 B classified irrelevant (116) or relevant (24), with a second `upk_read` decode pass over the relevant half and its failure reason (G1-22) |

| `FOOTAGE.json` | the same record, machine source: capture geometry and PTS-derived samples, file-side statements re-read from `WEAPONS.json`/`OFFSETS.json`/`MODES.json`, reason codes, per-row status |
| `GAPS.md` | coverage, native/untagged objects, dependency closure, verification |
| `objects.jsonl` | one JSON record per export (tags, refs, parse status) — the machine source |

Consumers must read these files through `Tools/scripts/grab_model.py` (schema 6)
and run `python Tools/scripts/grab_model.py check`; other readers are unsupported.
