## 2. Classification rule (mechanical)

| class | rule |
|---|---|
| `same-role` | the BmAK parameter name exists verbatim in the donor `vehicles` bank **and** the pair's donor event is the engine-role event. Both halves are decoded values; nothing is inferred. |
| `plausible-by-name only` | the donor event role is only adjacent (`GearChange` for a gear-shift event), or a donor parameter name shares the parameter's word stem (`REV_RPM` / `rpm`, `EngineHeat` / `heat`). Names only: the donor edge is undecoded. |
| `no counterpart` | no donor event role for this event's job and no donor parameter name that matches or shares a stem - including every unresolved `0x...` parameter hash, whose name is UNKNOWN. |

`x range` is derived: the smallest and largest x over all curve points of that bind across every package that carries the event. `curves` is the number of distinct curves found for the same (event, parameter) pair.
