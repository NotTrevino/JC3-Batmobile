## Operator statements recorded with this file (2026-11-05, operator-stated, not decoded)
- Inside the Batmobile BmAK controls replace all JC3 controls; JC3's pause and commlink keep priority. Enter with JC3's Y; exit with LB.
- Eject is A A (the menu's "Eject Into Glide"); in battle mode it is not possible while moving (boost is forced).
- The Power Winch moves to d-pad RIGHT and works like tethering the Batmobile to something else, using the donor's tether mechanic. The menu above
  shows d-pad right already used by Mission Select (position read from the drawn leader lines, not certain), so the winch binding needs the operator's decision.
- DECIDED (operator, 2026-11-05): the winch takes d-pad RIGHT and REPLACES Mission Select (JC3 has no BmAK missions). Unlike BmAK, the winch can
  attach to anything Rico's grappler can grapple; the design borrows heavily from Rico's grapple, mostly its tether mode (the closest match).
- DECIDED (operator, 2026-11-05): AR Challenges is not needed either (no JC3 carrier required); the d-pad rows AR Challenges and Mission Select are dropped.
