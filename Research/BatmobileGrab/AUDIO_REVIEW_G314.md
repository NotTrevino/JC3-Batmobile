## UNKNOWN

- **Where a missing id is actually played from.** Every bank the map references was searched; if an id is in none of them, its home is a bank the map does not name (a `Ww_*` bank inside a level package) or a `.bnk` file. The 14 `BKPK`-magic `.bnk` files are not a container this tool parses, so they were searched as raw bytes only. Where it would be found: the Wwise `SoundbanksInfo` manifest (none under the install root), or a name-table scan of all 4,145 packages for the event's owning bank.

- **Whether a HIRC Event's action list resolves to real media.** The event id is declared by the bank; its actions were not followed into `CAkActionPlay` / `AkBankSourceData`, so the media the event would play is not verified here.

- **The other seven claimed-missing banks.** Three are audited end to end; the remaining seven are quoted from G3-14's table and were not re-read by this tool.

- **Whether the game loads these packages when the car exists.** File facts only: no process was launched or attached.
