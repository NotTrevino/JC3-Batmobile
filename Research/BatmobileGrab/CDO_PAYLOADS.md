## 2. Method

- **prefix**: a CDO component payload starts with 12 bytes, `00 00 00 00 4e 14 00 00 00 00 00 00` for the first one; bytes 4..7 are the export's own name-table index. Decoded: it resolves to the object's own name on all six, which proves where the tag stream starts.
- **tags**: `upk_read.walk_tags(pkg, payload, 12)` - the uncooked Batman tag format (int16 type, uint16 layout offset, then an inline value or FName+size+index).
- **naming**: each tag's layout offset is resolved against the generated BmSDK-AK class and its ancestors (most derived wins); the SDK stores the offset as decimal `Ptr + N` in each accessor, so the map is read from the source, not guessed.

## 4. What this closes

- The six payloads are **decoded**, not skipped: two `StaticMeshComponent`s carry `ReplacementPrimitive = null` and `PerInstanceRandom`, and the four `SVehicleWheel`s carry **no serialised tags at all** (their values are the class defaults).
- No tag is UNKNOWN: every layout offset resolves to a BmSDK-AK member, and the package's own `ReplacementPrimitive` name agrees with the SDK's member at the same offset - an independent cross-check of the naming.
- The 512 MiB budget did not protect against a misparse; it prevented a ~645 MiB decompression. The payloads are 14-67 B once reached.
