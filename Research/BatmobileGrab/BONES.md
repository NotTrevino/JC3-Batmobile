## 9. Limits and reproduce

* Ownership uses the `>= 0.5` threshold exactly. A point with two equal maxima would be ambiguous; this mesh has 0 / 0 / 0 such points, so none are guessed.
* Split faces are not assigned to a bone. Per-bone `kind=1` rows are touching evidence and can overlap; they are not ownership.
* LOD1/LOD2 section order is mapped to the cooked section material index and verified against the face count of every section, not assumed from a material name (PSK `MATT` names are generic `material_N`).
* The external LOD1/LOD2 exports are not in the repository. Reproduce with an isolated `umodel.cfg` (the user's config is not edited):

```bash
python Tools/scripts/grab_bones.py --write
```
