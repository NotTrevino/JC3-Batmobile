## Method and anchors

- **ids**: FNV-1(lower-case name): offset 0x811C9DC5, prime 0x01000193, XOR then multiply - reproduces 118/118 event ids in AUDIO_MAP.json.
- **RTPC**: u16 count before the list; entry = u32 param_id, u8 type (0), u8 interpolation, u8 a, u32 curve_id, u8 b, u16 point_count, then point_count * (f32 x, f32 y, u32 curve_type).
  - u16 before the chain == number of entries that parse
  - every entry type byte == 0
  - every point finite, |value| < 1e7, curve_type <= 32
  - no param_id is a HIRC object id
  - the BML_Steering parameters resolve to the AkParameterName list
- **Loudness**: ITU-R BS.1770-4: K-weighting biquads at 48 kHz, 400 ms blocks with 75% overlap, -70 LUFS absolute gate and -10 LU relative gate; channels weight 1.0.
- **Loop field probe**: Sound body bytes 4..8 (plugin type, 0, codec id, 0, stream type) do not separate looping from one-shot events (8 vs 32 rows probed), so the Wwise loop bit is not pinned here - per-event loop evidence is the `Stop_` counterpart, the name tokens and any vgmstream loop lines.
