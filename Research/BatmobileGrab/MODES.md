## Units

| basis | meaning |
|---|---|
| `conv` | the field's name under UE3 conventions: seconds, centimetres, cm/s, plain-float
| | degrees, and `factor` for a value the name calls a factor/scale |
| `engine` | an engine torque / force / impulse / power magnitude - UE3 documents no
| | conversion, so the shipped number is carried as-is |
| `type` | the slot type says what it is: object ref, name, bool, struct, curve |
| `none` | the name does not say what the number counts: reported raw, **never guessed** |

## The ledger's parenthetical counts

`T-BM1` writes `BattleMode*` (9), `TurnOnSpot*` (3), `TransformationTurn*` (2). Those are
**serialised** counts, and in each case the simulation class is what is being counted:

| row | token | ledger | declared | serialised (sim) | serialised (vehicle) |
|---|---|---|---|---|---|
| `T-BM1` | `BattleMode*` | 9 | 42 | 10 | 5 |
| `T-BM1` | `TurnOnSpot*` | 3 | 4 | 3 | 0 |
| `T-BM1` | `TransformationTurn*` | 2 | 4 | 2 | 0 |

The ledger's (9) counts the scalars; the record carries 9 of them plus 1 curve member
(`BattleModeVSpeedCurve`, `FInterpCurveFloat`), so the serialised total on the simulation class
is 10.

The vehicle class carries the rest of the `BattleMode*` family (5 serialised fields
on `RVehicleBatmobile`: the battle-mode primary weapon, the yaw offset and the
three-value impact-speed band), which is why this record counts more than the
ledger's (9). `ArmourModeDamageReduction` carries its own prefix, so it is not part
of that count - the row names it singly and the check above confirms its value.

## Gaps

- **61 of 107 declared fields carry no value in the files.** They are declared by the class
  and absent from every archetype's tag stream, so the number that actually runs comes from
  the engine or BmScript defaults, which are not in this grab (`BMSDK_OFFSETS.json` has the
  declaration only).
- **5 serialised fields are missing from at least one archetype**: `BattleDodgeImpulse` (Joker),
  `ArmourModeDamageReduction` (Joker), `PMDodgeTorque` (Joker), `PMDodgeForce` (Joker),
  `PMDodgeDuration` (Joker). A missing tag is not a zero: a cooked archetype omits a property
  that equals its class default, so the value that runs in those packages is a `Default__*`/CDO
  number the grab does not hold - **UNKNOWN** from the files, never 0 and never "no such
  behaviour".
- The camera family (`BattleModeCam*`, 8 fields) belongs to the camera cards; it is listed
