  25,252 of 36,310,271 bytes on the first bad byte - recorded here so the method is not
  mistaken for a whole-image linear disassembly.
- `.pdata` chunks are merged where they fall through (tail mnemonic not `ret`/`jmp`),
  reproducing §1's sizes as oracle `O3`.
- readers = the merged functions containing §3's whole-function entries and §5's functions;
  callers = functions holding a `call`/`jmp` site whose target is inside a reader.
- writers = cache instructions with `CS_AC_WRITE` at `+0x150`/`+0x158` inside those
  functions. Each hit is re-decoded from the exe bytes (`O5`) and tested against the width

  another class's field, not the node pointer.
