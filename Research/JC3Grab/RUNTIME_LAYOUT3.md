* **A fixed address that leads to a spawned vehicle.** Tried: whole-function rebuild (§1),
  the refuted chain (§2), five-level caller walks (§3), every RIP-relative operand in the
  closure (§4), and a whole-image register-provenance scan for global -> `+0x150`/`+0x158`
  with static dereference of every candidate (§5). No candidate's global holds a canonical
  pointer in the image, so a node cannot be reached statically. Where it would be found: a
  runtime dump after a vehicle spawns, or the allocator that stores the node into the
  global (the store instruction, not the initialiser).
* **Which world pointer the raycast path uses** (`node+0x150` vs `+0x158`). Both are read
  in the same functions and never compared - G3-07a's UNKNOWN 2 stands.
* **The render-instance transform and the loaded-resource table.** No anchor reaches a
  draw instance or a resource table, so this render writes neither.
