## 8. Oracles used

- cinfo array: pointer bijection onto the constraint objects + 24-byte spacing (measured) + the field at +0x0C constant 0x7FFFFFFF fleet-wide.
- constraint atoms: 3x4 rotation test (unit rows, orthogonal, det = +1) rather than a fixed offset, because the atom block length varies; pivots are the translation 16 bytes after the rotation.
- mass float: the same offset +0x28 in every object and every file, strictly positive fleet-wide, rank-correlated with hull volume.
- body entries: 24-word domain census over all fleet bodies (zero / pointer / constant / float-like counts), so a field is called a pointer only when the packfile's own fixup table says so.
- ids and compounds: cross-checked against the grab's parts table (body names) and the packfile's own reverse pointer map.
