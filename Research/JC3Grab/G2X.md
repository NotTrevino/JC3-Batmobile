## 4. What the gate still cannot prove

* A proven absence is an absence of **names in the decoded fleet**, not of engine
  capability. Every row that leans on native code says so: turn-on-the-spot (G2-21),
  the eject launch (G2-20), the effect trigger names (G2-22), the graph bytecode (G2-17).
* Three rows carry a value the files do not give: the mass unit (DIM-3, G2-34 says
  UNKNOWN), the explosion-threshold semantics (G2-28 step 7) and whether the module or
  the `.epe` light list renders (G2-33). None is filled in here.
* The carrier is not the build: HUD-1/HUD-2 need the entity -> `hud.gfx` bridge, which
  is game code (`JC3_HUD_WEAPONS.md`).
