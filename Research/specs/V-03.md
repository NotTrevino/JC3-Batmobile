## 4. Plan

### 4.1 Files to create

| file | role |
|---|---|
| `Tools/scripts/v03_wiring.py` | the gate: `--check` runs G1…G5 and writes `Builds/bm-RC1/verify/wiring.json` + `wiring.md`; exit 0 only when `dangling == 0` |
| `Tools/scripts/v03_ids.py` | the id resolver: builds `{hash: name, path}` from `INDEX.jsonl` + `WEAPONS*.jsonl`/`WEAPONS_SHARED.json`, prints every graph weapon id with `resolved` or `UNKNOWN`, writes `Working/Wiring/weapon_ids.json`; **never** guesses a name |
| `Working/Wiring/weapon_ids.json` | the evidence file: `{"851CAABE": {"status": "UNKNOWN", "tried": [...], "row": "T-WP1"}, …}` |
| `Builds/bm-RC1/verify/wiring.json` | the card's output (the card names none): counts per class + every dangling reference with its file, member and row |

### 4.2 Steps

0. **Preconditions.** Require `Builds/bm-RC1/receipt.json`; enumerate every edited module from it
   (`.vmodc`, `.epe`, `.onlinec`, `.ee`) and slice each through the RC `.toc`. Missing RC →
   `BLOCKED: Builds/bm-RC1 missing (B-14/gate BX)` exit 2. Today: stops here.
1. **G1 points.** Parse the RC `.epe` (ConvertProperty → XML, or `bm_entity`'s parser). For every
   `SWeaponPoint` (class hash + name): resolve its parent object; require the parent to exist in the
   same graph; if the parent is a `CBulletWeaponBase`, require that **the component is reachable from
   a part** through `attach.vehicle` / the `CCar` slot, and print the part it reaches; flag duplicate
   `(parent, name)` pairs. Prints
   `points N: parent ok N, duplicate 0, part-unreachable K`.
2. **G2 weapons.** `v03_ids.py` resolves every id slot the graph binds (`id:851CAABE`,
   `id:00568A74`, plus the two clones). Each id must print `resolved <path>` (then G3 checks the path)
   or `UNKNOWN`; an `UNKNOWN` id is a **failure with its own line in `wiring.json`** — the card's
   "every weapon id exists" cannot pass on an unresolved id.
3. **G3 references.** Collect every path/GUID from the built modules and the manifests — weapon paths
   (`WEAPONS_SHARED.json`), effect paths (`t17_fx.json` rows), lights (`t14_lights.json` 28 rows +
   `lights_manifest.json` 24 blocks), sound GUIDs (`bm_bank_manifest.json` 45 GUIDs / 5 events),
   Rebel Drop entity path (B-13). For each: if it names a file in the build, it must exist there;
   otherwise `jc3index.py resolve <full path>` must return a row. One line per reference:
   `ok build`, `ok archive <archive>@<offset>`, or `DANGLING`.
4. **G4 drop.** Resolve the Rebel Drop entity path through the same rule. Today: no path exists →
   `DANGLING` with B-13's blocker text, not a skip.
5. **G5 report.** `wiring.json` with `counts{points, weapons, effects, lights, guids, drop}` and
   `dangling[]`; `wiring.md` one section per gate. Exit 0 iff `dangling == 0` **and** no `UNKNOWN`
   id remains.

### 4.3 Ordering

G1 needs G0's slice; G2 → G3 (ids become paths); G4 is independent. The gate never writes outside
`Builds/bm-RC1/verify/` and `Working/Wiring/`.

1. Set one `SWeaponPoint`'s parent to a name not in the graph → `parent ok N−1`, named failure.
2. Change `id:851CAABE` to `id:DEADBEEF` → G2 `UNKNOWN` line, exit 1.
3. Delete one `.rbm` named by `lights_manifest.json` from the RC tree → G3 `DANGLING`.
4. Remove one GUID from `bm_bank_manifest.json`'s list and keep the `.ee` entry → G3 asymmetry.
5. Rename a part in the `.vmodc` (`batmobile_turret`) while the graph still binds it → G1
   part-unreachable.
6. Add a second identical `(parent, name)` point → G1 `duplicate 1`.
7. Point a weapon path at a file that exists in no archive → `DANGLING`.
