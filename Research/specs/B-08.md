`EngineNitro`" — so the attachment already exists; what the body rebuild changed is **where the tail
is** (R3: physics and visuals move together). The edit is therefore the attachment's `world`:

* translation = `Afterburner` socket `pos_m` `[-0.009578, 0.537762, 3.393177]`;
* rotation = the socket's measured basis (`forward_jc3`, `up_jc3`, right = forward × up), emitted in
  the mat layout B-05 measured (rows 0–2 = X/Y/Z axes, row 3 = origin, det +1 asserted);
* `Usage` unchanged (4197885156) and `Effect` unchanged (3518298851) — both re-derived and asserted,
  which is exactly what Done 1/2 mean;
* `exhaust_upgrade_nitrous2` (the twin, `x = −0.4101563`) is **decision D-B08-1**: either mirror it to
  the same socket with the x sign kept, or leave it at the donor offset. The measured default is

  at ±0.41 m from a jet at x −0.0096 would sit outside the rebuilt tail. Decision recorded in the
  spec file, verified in game by Q-1 #5 — never silently chosen.

## Tamper tests the `--check` must pass

1. Change an `Effect` int by 1 → Done 1 fails ("matches no path").
2. Change a `Usage` to a random u32 → Done 2 fails with `UNKNOWN`.
3. Move the nitrous attachment 5 cm off the socket → Done 3 fails.
4. Drop one `SAttachedEffect` → Done 1's count drops and the matching FX row is reported missing.
5. Point `Effect` at a path that exists in `FX_TABLE` but whose container is 0 → Done 1 fails on
   resolution.

Each is applied to the build, captured, then reverted from a `sha256sum` manifest taken first.
