## 4. Build plan (reproduction from a clean tree)

**Files to create:** `Working/Collision/batmobile.physicsc`, `Working/Collision/bm_collision.json`,
`Working/Collision/BM_COLLISION.md`, and the generator `Tools/scripts/bm_collision.py`
(`--write` / `--check`; no third mode). The writer itself is `jc3hkx.py`, reused — never
re-implemented (R2's spirit: one implementation per transform).

**Step 1 — read the plan, not a guess.** `build()` loads `t16_collision.json` (slot set), B-02's
`body_bbox_m`, the donor `.physicsc`, and `stations.json` (read only).

**Step 2 — the body hull, per axis.** Map the donor body hull's own AABB onto DIM-1's bbox with one
per-axis linear map (`k = [1.676257, 1.873759, 1.909565]`, `translate [-0.0005, -0.366422,
-1.126325]`), re-deriving **every plane** — 36 vertices / 47 planes / 1,776 B extent, radius
0.01 → 0.016763. The uniform `k` T-22 proposed is *inside* the body and is recorded as the rejected
control.

**Step 3 — the four wheel hulls.** `k = 1.660052` (2 × mean station radius), part-local centre so each
wheel still spins about its own pivot (R3), giving `0.491 × 1.3654 × 1.2986` m.

**Step 4 — the two door slots** copied byte-identical (see §1 note 2).

**Step 5 — re-box the 3 ancestor compounds** that contain the grown children (a grown child moves its
ancestors' AABBs — G2-30).

**Step 6 — write and re-read**: `packfile_bytes` → the file (same size, no new objects, pointer slots
stay 0), then `verify_written` + `shape_checks` + the `hknpPhysicsSystemData` comparison; only 483
ranges / 1,926 B may differ. Emit the JSON record and the MD from the same numbers.

**Step 7 — Done checks** → the commands of §3.

**Step 8 — tamper test on `--check` (3 cases, each restored byte-exactly).** (a) flip one plane
coefficient in the built file → `bm_collision.py --check` must fail "on disk differs from the derived
bytes"; (b) change `body_bbox_m` in the B-02 manifest by 1 cm → the union deviation must leave the
5 cm band; (c) add a byte to the file → the size/object-count checks must fail. The recorded session
reported 3/3 caught and reverted, and the uniform-`k` control failing at 0.8583 m.

**Step 9 — hand-off.** The `.physicsc` is staged into the build in the phase-B lineage step that owns
the `.ee`, followed by `eetoc` for its `.toc` record; V-01 re-checks it there.

## 5. Hard rules this spec keeps

No game launch (R6); nothing written under `D:\Games` or `E:\Games` (the game is only *read* by the
`--all` gate); no commit or push; no secrets; stations and `base_wheel_hardpoint_positions` are never

either printed by a command or read from the JSON record the generator wrote (R11); nothing is
`UNKNOWN`, and where a value would have to be invented the card is silent and so is this spec.
