# B-16 build spec — winch anchor on the entity graph; the pull loop is code

Card source: `tmp/freebuff/reports/winch-and-tether.md` (WPN-6 / WLD-15 / WLD-17), ledger rows
`T-WP6` (blocked), `T-WLD15` (next), `T-WLD17` (blocked), operator decision 2026-11-05 (winch on
d-pad RIGHT, replacing Mission Select).

**SUMMARY: PART BUILDABLE, PART CODE.** The entity-graph half of the winch is decoded and can be
authored in the B-05 step (an anchor object with a transform and an enable/disable pair, a drum
mesh, the two rope components and the VFX/SFX). The **pull loop** — force toward a target, a length
clamp, a reel rate and a release — is not data in JC3: 0 of 53 module types, 0 of 67 part
behaviours and 0 functional winch classes. Helicopter airlift is **data-blocked**: 0 of 23
helicopters carries a `CVehicleCargoBay` and the class census has no helicopter hook class.

**Attach point (decoded):** `WinchOrigin`, bone `Batmobile_Chassis`, relative location
**(286.554, 0, 59.0) cm**, rotation **identity** (`relative_rotation_deg` null, quat 0,0,0,1) —
`Research/BatmobileGrab/SOCKETS_JC3.json`. The four `HangFromRope_*` sockets sit at z **460.50 cm**
on the wheels and are the rope-hang anchors, not the drum.

**World matrix:** translation-only from the socket above; no rotation to bake. Units: BmAK cm, so
the object's `world` is built at (2.86554138, 0, 0.58999992) m in the entity frame.

**Parameters that cannot be authored (code-level):**

- cable **length** (BmAK has only the function `RestoreOldRopeLengthIfShorter`, no member);
- **force / pull** (no tether or winch force exists in any table; the only numbers are the damage
  gate `grapple_pull_armor` -1..0 and `grapple_pull_armor_strength` 0..100.0);
- **reel rate** and **release** (both `enable`/`disable` events ship empty on all 12 bays and all
  33 `CGrapplingHookPropData` tags);
- the **6,000 mass** target is a ratio, not newtons: 6,000 / 975 = **6.154x** the donor's class, and
  BmAK's own feat bound is **>= ~2 t** — below a 6 t car, so BmAK's numbers do not lift it either.

## 2. Steps

1. Insert objects 1-4 above into a private `.epe` copy; read back every member and the `world`.
2. Keep the anchor's `enable`/`disable` empty (matching the fleet) until a release action exists.
3. Write the pull loop **outside data**: a per-frame force toward the hit point, a length clamp, a
   reel rate and release on the d-pad RIGHT action. The only JC3 precedent is
   `graphs/dualtether_test_to_vehicle.gdc/.gsc`, which is unread → UNKNOWN.
4. Helicopter bay (T-WLD17): clone `CVehicleCargoBay` onto a helicopter entity and probe whether the
   native attach rule accepts a car — the bay's own events are empty, so the rule is engine-side.
   Until that probe, the plane's bay and the compound
   `v4603_plane_urga_cargotransport_military_cargo_tank` (`CAirPlane` + `CCar`, 25,000 + 40,000)
   remain the only decoded vehicle-carry.
