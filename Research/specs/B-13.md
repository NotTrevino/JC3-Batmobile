### 3.2 `bm_rebel.py` — steps and what each one asserts

1. **Read** `t15_world.json` (recipe + WLD rows, refusing unless `t15_world.py --check` is green —
   B-3 becomes a precondition inside the script, not a note) and `REBELDROP.json` (donor item).
2. **Copy** the patch-layer `profile/item.onlinec` into the tag tree (never the archive, R7/R10);
   record `sha256` of the source so "the shipped game file is untouched" is provable.
3. **Rebuild the array**: append one 128 B record at the array's end, shift the string area by
   `8 + len(leaf) + len(leaf_desc)` (both NUL-terminated), rewrite **every** string pointer
   (`UIImagePath` at 88, `UIVideoPath`, `Feats`) by the same delta, bump the array count and the
   root size fields. Assert: 197 records decode, `UIImagePath` resolves on **197/197**, the 196
   carried-over records are byte-identical after pointer normalisation.
4. **Write the 26 members** at their decoded offsets from `REBELDROP.md` §2 (offsets, not names,
   R4/R5): `Name` = `UIName` = `hash_jenkins(leaf)` recomputed in the script, `BaseName` =
   `hash_jenkins("v0300")`, `UIImagePath`/`UIVideoPath` = the leaf, `Type` 1, `UIType` 3,
   `UIFlag` 5, `UIDisplayOrder` 12, `RebelDropTimer` 1800, `Rewardable` 1, `DlcId` 0,
   `UITypeDescription` 2432797658, `UIFlagDescription` 1383769868 (category text, kept per T-WLD7),
   `UI*Par*` from the recipe.
5. **task.onlinec**: append the `ItemReward` link (permanent 1, quantity 1, threshold 1,
   delivery 0) to task 1361701860; assert 591 → 591 tasks with 1 changed record and 0 moved
   offsets (if the reward is deferred, the script prints `reward: skipped (T-WLD1 row 2 gated)`).
6. **Icon**: copy the 18,688 B donor `.ddsc` under the new leaf; assert size + `sha256` equal, and
   that the name is the leaf the item points at.
7. **Entity link**: assert `<build>/aaf/editor/entities/jc_vehicles/01_land/v0300_car_kensington_sportsmuscle/v0300_car_kensington_sportsmuscle_batmobile.epe` exists **and** is listed in `@files.xml`; hard-fail otherwise (this is Done-2, not a warning).
8. **Pack** (`SmallPack`), **verify** (`SmallUnpack` + `aafdiff --hash` vs base = exactly the 4 named files), **`.toc`** internal for both `.onlinec` paths (`eetoc patch --internal`), re-read every `.toc` record against the `.ee`, **budgets** (R9: Model 4,915 KB / Texture 7,065 KB; the icon adds 18,688 B texture), receipt + installer.

`--check` re-does 1, 3–8 read-only and prints one line per assertion; exit ≠ 0 on any.
