### Blockers

**None.** No dep is missing (`B-02`, `B-03`, `T-12`, `T-14`, `T-18` are all `done` in §12) and no
input the card consumes is `UNKNOWN`. The four items below are **noted, not blocking** — each is
already declared in the artefact that carries it:

1. **`bm_parts.py --help` raises.** `argparse`'s help formatting fails on this script's description
   (`TypeError` inside `_print_message`). The modes the card uses (`--write`, `--check`) run; the
   text is readable in the module docstring. Cosmetic tooling defect.
2. **R9 model budget is reported as a delta, not a pass.** `Builds/bm-002/receipt.json` records
   `model_kb 8077.456` against `model_cap_kb 4915.0` with 222 files, and its own note says this
   counts **every distinct `.rbm` the built module references**, including the 40 shipped Serpente
   part meshes the module still carries — it is *not* the R9 appearance figure (B-02 measured
   4,790.9 KB, B-03's net 4,899.6 of 4,915 KB). bm-002 does not re-emit body/wheels, so the receipt
   reports the delta (`+1045.1 KB` vs bm-001) and leaves R9 open for the step that re-emits them.
   Correct accounting, not a failure — but a reader must not quote 8,077.5 KB as the vehicle's model
   budget.
3. **`Boat_Antenna` has no `VehicleDamage` row.** `jc3parts.py check` prints it: the part falls back
   to the module's `Default` row (the donor's own `Boat_Antenna` part does the same). No row was
   invented (R4); remapping that type is a T-12 decision.
4. **`receipt.json` `checks` is `[]`.** The Done criteria are printed by `bm_parts.py --check`
   (quoted below) but not stored in the receipt; the durable record is the §12 row + MODLOG.
