| file | content |
|---|---|
| `Tools/scripts/bm_rc.py` | the RC aggregator + `--check`: builds `Builds/bm-RC1/` from one source tree per contributor card, writes `receipt.json` with **every** file's `sha256`, generates the installer, then proves receipt ↔ installer ↔ tree agree |
| `Builds/bm-RC1/aaf/` | the merged dropzone source tree (one, not a variant set — D-2) |
| `Builds/bm-RC1/banks/` | `vehicles.bank`, `weapons.bank` from `bm-004` (git-ignored large files, staged not committed, R10) |

| `Builds/bm-RC1/receipt.json` | `schema 2`: `files[{path, bytes, sha256, owner_card, internal, source_sha256}]`, `replaced[]` (dropzone originals + backup names), `budgets`, `checks[]`, `deps{}` |
| `Builds/bm-RC1/install.ps1` | `-Action Install|Verify|Rollback091|Status` **plus `-WhatIf`** (emits the receipt's file list and exits 0, writes nothing) |

| `Research/specs/RC_INSTALL.md` | the rollback plan for every replaced file, including the banks (`*.bm-RC1-backup`) and the profile tables |

### 4.2 `bm_rc.py` steps, each asserting

1. **Refuse to start** unless every `deps` entry in `Working/RC/bm_rc_manifest.json` has its §12 status
   `done` (or `skipped` by decision) **and** its `source` tree exists — the manifest names B-05…B-13;
   this turns the B-14/1 blocker into an assertion instead of a footnote.
2. **Merge** each owner card's tree into `bm-RC1/aaf`; a path claimed by two cards is an error; a path
   the owner card's receipt never mentions is an error (`owner_card` provenance on every file).
3. **Hash everything**: `sha256` + `bytes` for every file in `aaf` and in `banks/`, sorted; the list
   length must equal the file count on disk (no glob that silently under-matches).
4. **Pack** and **`.toc`**: `SmallPack`, then `eetoc patch --internal` for each module the card set
   names, then `eetoc compare <ee> <toc>` must agree, and every internal record re-read against the
   unpacked tree.
5. **Diff** `aafdiff --hash` base (`bm-001`) → RC; the changed set must equal the receipt's
   `files[].path` set minus the always-shipped identity files.
6. **Installer**: generate `install.ps1`; `-WhatIf` prints `receipt.files[].path` + `sha256` + action
   (`add`/`replace`/`backup <name>`) and **writes nothing**; `-Action Status` prints installed vs
   receipt; `Verify` re-hashes the dropzone; `Rollback091` restores every replaced file from its
   backup and deletes every file this build added.
7. **Rehearse offline** exactly as B-11 did: a simulated `-GameDir` under `tmp/`, never `D:\Games`
   (R6), covering (a) clean install → verify → rollback → `sha256sum -c` of the restored bytes,
   (b) install over a decoy-vanilla dropzone → backup created → rollback restores it.
8. **Budgets** (R9) and `spec_check.py` on the merged assemblies; both printed, both gating.

`--check` re-runs 2–8 read-only (rebuilds the receipt in memory and compares to the committed one) and
prints `check ok` with the file count, the `.toc` record count, and the two budgets.

### 4.3 Done criteria → the proving command

| card Done | proof | expected |
|---|---|---|
| "receipt lists every file with sha256" | `python Tools/scripts/bm_rc.py --check` | `files <N> every file hashed` where `N` == `find Builds/bm-RC1/aaf -type f | wc -l` (+ banks), and `rehashed <N>/<N> ok` |
| "installer `-WhatIf` lists exactly those" | `powershell -NoProfile -File Builds/bm-RC1/install.ps1 -Action Install -WhatIf` then diff against the receipt | the two lists are identical and non-empty; `wrote 0 files`; exit 0 |
| rollback plan per replaced file | rehearsal (a) + (b) in a `tmp/` dropzone | `Install` → `Verify` green → `Rollback091` → `sha256sum -c` of the restored originals OK, backups removed, added files gone |
| "one tree per variant set" | `ls Builds/bm-RC1` + `t11_variants.json` | one tree; `variants` says `drop_entries 1`, `entities 1` (D-2 one hybrid) |
| tamper tests on `--check` | 5 tampers, each restored | all caught: (a) flip one byte in a mesh → `sha256 mismatch <path>`, (b) delete a file from the tree → `receipt lists 1 missing file`, (c) `@files.xml` loses a path → `not registered`, (d) `.toc` record offset 0 for an internal module → `internal record missing`, (e) `-WhatIf` list edited by hand → `installer ≠ receipt` |
