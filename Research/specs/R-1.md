### 4.3 `Tools/scripts/release_manifest.py`

Two modes, one source of truth.

- `--write` — creates `Builds/release-1/` from scratch (refuses if it exists and `--force` is not
  given), copies every file the allowlist matches, refuses any path matching a forbidden extension
  or living under an excluded directory, and writes `release_manifest.json`:
  `{schema, generated_by, source_root, files: [{path, bytes, sha256, source_sha256}], counts:
  {files, bytes, by_ext}, required_docs: [...]}`. Counts are computed, never typed (R11).
- `--check` — re-derives and compares, with no writes. It fails (non-zero, named reason) if:
  1. a file on disk is missing from the manifest, or a manifest file is missing on disk;
  2. any `sha256` differs from the manifest, or `source_sha256` differs from the repo file;
  3. any file carries a forbidden extension or sits in an excluded directory;
  4. any file's bytes exceed the size cap;
  5. `RELEASE.md`, `README.md`, `CREDITS.md`, `AI_DISCLOSURE.md` is missing;
  6. `README.md` lacks the headings `## Requirements`, `## Install from your own games`,
     `## Build`, `## Uninstall` (the anchors the card's Done 2 needs);
  7. `CREDITS.md` lacks `Rocksteady`, `Warner`, `Avalanche`, `Gibbed`, `vgmstream`, or the "no assets
     redistributed" sentence;
  8. `AI_DISCLOSURE.md` is empty or still contains the `TODO` placeholder;
  9. a published text file contains an absolute user path (`[A-Za-z]:\Users\`), matching the lint's
     own rule;
  10. `um publish check <folder>` reports any `FAIL` or any `WARN` (the command is invoked from the
     release folder so the card's `.` form is what is tested; `--skip-lint` exists for a quick
     manifest-only pass and is never used for the Done run).
- `--check --manifest <path>` — the same checks against a copy, so the tamper test can mutate a copy
  and prove each assertion fires.

No hand edits to `release_manifest.json` (R11); it is generated.
