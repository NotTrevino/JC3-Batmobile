build B-05 creates (B-07's own `Do` is a rewrite *inside* a build, and the entity that B-05 grows is

```

$ python Tools/scripts/bm_lights_mod.py --check
```

The check must assert, per entry: `part` ∈ the parts module, `part_index` == that part's index,
`has_lights == 1`, `part_hash == hash_jenkins(part)` (the recipe §1.3 verified 21/21), and that no
entry still names a `sportsmuscle_taillight_*`/`signal_*`/`headlight_*_0N` donor part. It must also
print the two absences (high, brake) and the transform's UNKNOWN state rather than passing them
silently.

**Reachable today?** No — the criterion is written against a build that B-05 has not produced
(BL-1). The parts half of it already holds (`bm_parts.py --check` above); the module half cannot be
run until `Builds/bm-003` exists.
