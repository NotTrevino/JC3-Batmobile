### Step 1 — `Tools/scripts/sim_install.py` (new; `--write` / `--check`, the only writer)

One script, one JSON, the pattern every B card uses (`--check` re-derives, never repairs).

```
python Tools/scripts/sim_install.py --write [--from "D:\Games\Just Cause 3\dropzone"] \
       [--sim E:\Modding\_dropzone_sim] [--rc Builds/bm-RC1]
python Tools/scripts/sim_install.py --check
```

`--write` does, in order, and stops at the first FAIL:

1. **guard** (no writes): call `deploy.read_installer_hashes('Builds/bm-001/install.ps1')`, hash the
   live `…\v0300_…_civilian_01.ee` + `.toc`, and require equality (`guard: live dropzone == bm-001`,
   the test-091 identity). Record both hashes. If the live file is absent, record
   `guard: no live dropzone file (clean install)` — the card's dry run still needs the copy, so a
   missing live dropzone is a FAIL for V-06 (unlike a build, V-06 must copy something that is
   test-091).
2. **snapshot** the source tree: every file under the dropzone → `{rel, bytes, sha256}` written to
   `Working/Deploy/before.sha256` (GNU `sha256sum` format, so `sha256sum -c` is the independent
   second opinion).
3. **copy** the whole dropzone into `E:\Modding\_dropzone_sim\game\dropzone`; re-snapshot the copy
   and require it to equal `before.sha256` (a bad copy must not be mistaken for a bad install).
4. **`-WhatIf`**: `pwsh -NoProfile -File Builds/bm-RC1/install.ps1 -Action Install -WhatIf
   -GameDir E:\Modding\_dropzone_sim\game`; capture stdout; parse the listed paths; require the set
   to equal the receipt's `files[].vfs`. Also re-snapshot the sim and require **no change** (a
   `-WhatIf` that writes is BL-4's trap).
5. **Install** on the sim; walk the sim and classify every difference against `before.sha256`:
   `added` (in receipt, not in before), `replaced` (in both, hash changed), `unexpected_changed`
   (changed but not in the receipt), `missing` (in the receipt but not on disk after install).
   Require `unexpected_changed == []` and `missing == []`, and `added ∪ replaced == receipt set`.
6. **Rollback**: `-Action Rollback091 -GameDir <sim>`; re-snapshot; require byte-for-byte equality
   with `before.sha256` and no `*.bm-*backup` / `*.bm-*` leftover anywhere in the sim.
7. write `Working/Deploy/sim_install.json` (schema 1, card V-06): guard, before/after counts, the
   four sets, the `-WhatIf` list, rollback diff, and every hash used.

`--check` re-reads the sim + the JSON and re-derives PASS/FAIL (no install, no copy). It must be
able to fail on: a byte changed in the sim after rollback, a receipt entry the sim lacks, a stray
file the install added.
