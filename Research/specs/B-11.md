# B-11 · Audio bank — build spec

**Summary: READY — and already executed.** Every input the card names is present and holds what the
card needs; no dependency is missing and no value the build consumes is `UNKNOWN`. The card is built
and checked in this tree (`Builds/bm-004/`, `Working/Audio/bm_bank_manifest.json`, §12 row
`B-11 | done`), so this document is the readiness audit plus the reproduction procedure: each step
names the command that proves it and quotes what that command printed. Route: **a + c** from
`Research/JC3Grab/JC3_AUDIO.md` §10 — a sample-payload swap inside a **private copy** of the shipped
banks (R7); no bank is authored, because the banks are FMOD Designer/Ex FEV v56/b50 and no `.fev`
project ships (route b = impossible).

### Blockers

**None.** No dep is missing (T-16 `done`), no input is absent, no value this build writes is
`UNKNOWN`. Four limits are recorded, not worked around:

1. **`tune→sample` is stored nowhere in the banks.** G2-24 measured 0/649 wave GUIDs in tune chunks,
   so the sample inside each tune is chosen by name/audition as test-060 did. A listener can still
   disagree with a chosen slot — that is a T-16 row, not a number B-11 can derive.
2. **W-03 (T-11's Vulcan loop) has no donor event GUID.** It resolves through its slot name in the
   built `weapons.bank`; the manifest says so instead of inventing a GUID (R4).
3. **`LandAudio`'s `min_rpm` 1,000 / `max_rpm` 10,000 have no proven runtime role** (G2-24) — B-11
   does not touch them.
4. **Loudness is matched to T-16's measured delivered value**; decoding the built bank back against
   the WAV source is **V-04's** gate and is not claimed here.
