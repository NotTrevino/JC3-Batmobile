LOCAL MODEL RULES

This project may be operated by a small local language model.

The model MUST NOT treat its pretrained knowledge as evidence.

For JC3-specific claims:

- Search local files first.
- Search Universal Modder knowledge second.
- Search documented external sources when available.
- Cite the evidence.
- If evidence is absent, say UNKNOWN.

Never fill missing information with a plausible-sounding JC3 implementation.

Prefer a 5-minute experiment over a 500-line speculative implementation.

Before modifying a file:
1. state the intended change;
2. identify the file;
3. explain why it is the correct file;
4. explain how the change can be reverted.
