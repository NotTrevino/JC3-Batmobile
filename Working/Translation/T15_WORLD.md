## 6. UNKNOWNs and limits

- **The `RebelDropTimer` unit** (1800 on the donor, 600…2700 fleet-wide) is a bare int32;
  seconds are plausible and unproven, so nothing is converted.
- **`Type`, `UIType`, `UIFlag` enum meanings** are UNKNOWN. Only the *description* strings
  resolve ("SPORTS CAR", "SPORTS CARS"), so the row copies the donor's values instead of
  picking a category.
- **`BaseName` is derived, not decoded**: it equals `hash_jenkins(<family prefix>)` on
  45/45 vanilla vehicle drops, which is strong but not a decoded
  field description (`REBELDROP.md` left it unnamed).
- **The string store has a writer** (`Tools/scripts/jc3strings_write`): bm-013 adds exactly 22
  pairs for the shipped `..._debug` leaf (1621485476 / 4081821928), 11/11 languages - so
  T-WLD4/T-WLD6 are `next` (carry the drop into the RC), not `blocked`.
- **The stunt areas are re-fittable**: 22/22 vertices place on the RC2 shell (P-1,
  0.036-0.105 m); full width needs 3 new deform indices (135+). Q-1 #3 is the standing probe.
- **The mass unit** is `UNKNOWN` (G2-34): the 6,000 target is a class value, compared to the
  fleet as a ratio, never as kilograms.
- **Native behaviour is not measured.** Tether strength, helicopter lift, traffic selection
  and water damage all end in game code; every `verify` cell is a §9b probe, and no game was
  launched here (R6).
