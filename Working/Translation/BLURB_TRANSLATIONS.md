## 5. What this does not settle

- **Register inside each language is a judgement, not a decode.** No file says whether
  "battle mode" should be a borrowed English term, a marketing phrase, or a literal one;
  the proposals pick the reading closest to the three vanilla samples.
- **`Batmobile` and `Arkham Knight` are left in Latin script**, matching vanilla prose that
  keeps `Kerner`, `Capstone` and `Urga` untranslated. Whether the localisation team would
  transliterate them (e.g. `Бэтмобиль`) is UNKNOWN - no file has that decision. The name
  pair itself is `BATMOBILE` in all 11 lanes, so the blurb is the only place a transliteration
  could appear.
- **Gender/case of the proper noun** (`La Batmobile`, `Das Batmobile`) follows common usage in
  each language; no vanilla string names a Batmobile, so there is no in-file oracle.
- The length budget is the vanilla maximum, not an engine limit. The store's text blob is
  NUL-separated with per-string offsets, so a longer string would still fit the format.
