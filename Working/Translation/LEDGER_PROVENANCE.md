## Method

- **translated_set**: the 85 rows LEDGER_AUDIT marks TRANSLATED, unchanged
- **cited_file**: parsed from the audit's evidence string (path before ':' or '@0x')
- **vanilla**: file in receipt.b18.reverted_to_vanilla, or owner_card has (vanilla bytes)
- **edited**: bytes differ from every earlier build's copy, or owner_card names a card this build's steps record as writing
- **inherited**: bytes identical to an earlier build, or owner_card names only that lineage; means not edited by bm-RC1
- **writer_cards**: B-04R, B-10, B-10b, B-10c, B-13b, B-15, B-16, T-13R
- **non_writer_cards**: B-04L (step says ported: False (no bytes written)); B-17 (step says SKIPPED); B-18 (moves files into .../batmobile/ and reverts to vanilla; no value edit)

The verdict is about the **file**, not the value. A file this build edited can still carry a donor value (the `.epe` tokens are the donor's graph names), and a file this build did not edit can hold a value an earlier build wrote. What the verdict settles is the audit's own definition - "present in a built file" - and whether the build in question is the one that produced that file.
