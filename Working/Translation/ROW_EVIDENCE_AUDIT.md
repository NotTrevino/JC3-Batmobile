## What this does not test

* **A field holding a different number.** Proving the file disagrees needs the field's
  row/key, which the ledger does not name, so it is UNKNOWN rather than clean. What is
  proven is presence, compared by value (`2.570` == `2.57`, and a value that rounds to the
  quoted precision counts as rounded, not absent). The number being present does not prove
  the row's reading of it.
* **Rows 41..145 of the resolved set** - out of scope by the card.
* **Whether the cited decode is still what the build ships** - that is `t_rows.py check`
  and the per-card `--check` scripts' business.
