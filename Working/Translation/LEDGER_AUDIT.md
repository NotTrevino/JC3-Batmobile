## Method

- **member_match**: segments (split on '.' after removing [...] and '/') overlap as a contiguous slice, either direction
- **value_match**: |built - row| <= max(1e-9, 1e-4*|row|); 1-digit tokens ignored; strings exact
- **string_match**: token >= 8 chars with '/' or '_' found as ASCII bytes
- **guessed**: value or string found AND the row carries one of by hand, hand-set, hand set, chosen, assum, unsourced, estimate, approx, guess, tuned, not law, probe, picked, eyeball, trial
- **not_translated**: no evidence; dispo out/superseded = declared, next/blocked = not built, otherwise no match

A row's cells are `[id, BmAK source, JC3 target, transform, now, proposed, confidence, verify]` (GRAB_BACKLOG.md section 7), but the JSONL was written by splitting markdown rows on commas, so a comma inside a sentence shifts every later cell. The audit reads the row as text and matches by content, never by cell index.
