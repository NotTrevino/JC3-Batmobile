## 1. What the index is, and why most chosen paths are not in it

`INDEX.jsonl` is the `jc3index.py` output: 1533 distinct FX paths exist in `FX_TABLE.jsonl`, but only 35 `.effc` files are standalone archive entries in the index. The rest are FX resources embedded inside an `.ee` entity container - still real, addressable through the container's index row, but absent from the path index by construction. So "not in the index" is not "missing" here; the audit checks the container.

The doc's **955** is reproduced exactly: it is the distinct paths whose `FX_TABLE` row has `root = EffectRTSystem` (955 of 1533 distinct paths). The other 578 paths are other effect roots, which is why the absence scans below use the 955 set the rows cite.
