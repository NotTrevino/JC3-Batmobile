# T-WP3b - JC3 carriers for the Batmobile's missile lock-on

**Answer: JC3 does carry it, and the missing piece is one named member, not a code class.** `WeaponTuning -> missile_weapon[].missile_base_tuning.missile_turning_speed` is the homing strength (0 = flies straight), and the fleet ships a *lock-on* AutoAim preset (`autoaim_vehicle_lockon_missile`) that differs from the no-lockon preset in 15 rows of three members, in all six shooter contexts: the two cone angles, the cutoff multiplier (500 vs 100/120), the distance fit weight, and vehicle targeting outside OnFoot. What the lock-on preset does **not** carry is a hold timer: the 22 members of `AutoAimSettings` include no duration, so BmAK's `MissileLockOnDuration` 2.0 s has no JC3 member and stays `UNKNOWN`.

Labels: `decoded` = read from a file at the offset shown; `derived` = computed from decoded facts; `UNKNOWN` = not in these files, with what was tried. Every number below is regenerated by `python Tools/scripts/t_wp3b.py --write`; none is typed by hand.

## 7. Contradictions found against the leads and against T7

1. **Operator lead "JC3 already has heat-seeking missiles and target lock": confirmed, with one qualifier.** Missiles home (`missile_turning_speed` > 0 on 16 tunes) and lock-on is a data preset. It is not universal: 7 of 11 vehicle missiles ship turning speed 0.
2. **`w613_fighterbomber_missile_ground_lockon` locks nothing** - `CanTarget*` 0/0/0, `MaxAimDistance` -1, `missile_turning_speed` 0. The name is the only thing that says ground lock-on.
3. **The lock-on preset alone does not guide.** `w621_advancedhelicopter_missile` binds `autoaim_vehicle_lockon_missile` on one build and still has turning speed 0, so preset and homing are two independent switches.
4. **`w612` is guided but bound to no driver slot** (`binding: []` on all three bomber builds), so it is a donor value, not a working weapon.
5. **T7's "no lock duration and no lock range" is half right.** No duration member exists (confirmed over all 22 `AutoAimSettings` members), but a range member does: `MaxAimDistance` - it is simply -1 (unlimited) in both shared presets, which is why the car-missile read missed it. `w609`'s own preset sets it to 750.
