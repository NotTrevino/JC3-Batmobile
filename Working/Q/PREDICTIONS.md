## D-2 - top speed (take A2)

| field | value | source |

| measured | **138 km/h** peak, still climbing when the brake went on | `T-E1` verify cell, `qa1_measure.json` `peak_kmh` |

| prediction | **267 km/h** terminal at the built Cd 0.55 | derived below: T-E2's 2921 N.m x the 0.65 wash at 4500 rpm into Cd.A = 0.55 x 6.635 m^2 |
| pass band | **240-294 km/h** (+-10 %, declared) | rolling resistance and driveline loss are not modelled here |
| class | **derived** (terminal balance) - the 300-336 km/h label stays **assumed** | `T-E5`, `T-E2`, `T-A2` |

```
P      = torque x wash x omega          (T-E2: 2921 N.m, T-E3 wash 0.65, 4500 rpm)
       = 894.7 kW
Cd.A   = 0.55 x 6.635 = 3.649 m^2     (built land_aerodynamics)
v      = (2P / (rho Cd A))^(1/3) = 74.21 m/s = 267.1 km/h
rho    = 1.2 kg/m^3
```

T-E5 is `assumed`, and this sheet does not treat the label as a measurement. The wiki's
209 mph is the mod's stated target, carried as the top of a **300-336 km/h** band;
BmAK has no speed member at all (T-A2 proves the chain carries no drag member either), and the
2026-10-23 sign-off covers the label, not a number read from a file. The label and the drag are
two decisions, not one translation: the Cd **0.1213** that used to be written to make 336.4
km/h reachable was reverse-engineered from the label and is withdrawn (correction 8391), so the
built member keeps T-A2's class fit **0.55** and the prediction above follows from it.

Any top-speed take therefore tests **reachability of a label, not fidelity to BmAK**: a terminal
inside 240-294 km/h is the prediction passing, and a terminal inside the
300-336 km/h label band would falsify the Cd 0.55 / T-E2 pair rather than
pass the label. The only measurement on record (138 km/h) was taken at Cd 0.139 on test-085,
before T-A2's edit, so it does not test either the label or the prediction.

## D-4 - turning circle (take A3)

| field | value | source |
|---|---|---|
| prediction, low-speed lock | **3.52 m** at 55 deg | derived: `5.029 / tan(55 deg)` = 3.52 m, `T-G1` x `T-ST1` |
| prediction, high-speed lock | **13.82 m** at 20 deg | derived: `5.029 / tan(20 deg)` = 13.82 m, `T-G1` x `T-ST1` |
| pass band | **3.17-3.87 m** / **12.44-15.20 m** (+/-10 %) | declared, not derived: tyre slip and the yaw response are not modelled here (the same declared slack D-2 uses) |
| lock angle | **55 deg at <= 20 km/h**, 20 deg at >= 72 km/h, falloff 1.5 | `T-ST1` |
| wheelbase | **5.029 m** | `T-G1` |
| time to full lock (built) | **0.80 s low / 0.60 s high** | `T-ST7` value cell |
| ruling goal - the failing band | **0.250 s low / 0.091 s high** (55/220 and 20/220 deg/s) | `T-ST7` next cell, operator ruling 2026-11-06 |
| **RED** | built **0.80 / 0.60 s** is **3.2x / 6.6x** the goal band 0.091-0.250 s | comparison below; stays red until take A3 measures it |

```
R          = wheelbase / tan(lock)              bicycle/Ackermann, no slip
wheelbase  = 5.029 m                          (T-G1)
lock       = 55 deg <= 20 km/h, 20 deg >= 72 km/h     (T-ST1)
R_low      = 5.029 / tan(55 deg) = 3.521 m
R_high     = 5.029 / tan(20 deg) = 13.817 m

t_built    = 0.80 s low / 0.60 s high            (T-ST7 value cell)
t_goal     = 55/220 = 0.250 s ; 20/220 = 0.091 s  (ruling)
rate_built = 55/0.80 = 68.8 deg/s ; 20/0.60 = 33.3 deg/s
slowdown   = 220/68.8 = 3.2x ; 220/33.3 = 6.6x
RED        = 0.80 / 0.60 s outside the 0.091-0.250 s goal band
```

The radius is geometry: with the lock angle and the wheelbase fixed, the circle is
3.52 m at the low-speed lock and 13.82 m at the 20 deg high-speed lock,
whatever the steer time. That is why the ruling's 0.25 s / 0.091 s is compared as a **time**
band and not as a radius band: it changes how long the car takes to reach the lock, so the
built 0.8 s / 0.6 s is 3.2x / 6.6x the goal and red.

Two limits are stated rather than folded into the radii: (1) the geometric radius is the
no-slip value, so a measured radius above it is understeer, not a failed derivation - hence
the declared +/-10 %; (2) the take's 60 km/h leg sits between the 20 and 72 km/h knots, and
the interpolation law between them is not decoded (only the 1.5 falloff), so that leg is
bracketed by 3.52-13.82 m and not pinned; the 100 km/h leg is the pinned one.

`--check` passes when the radii re-derive from the built locks and wheelbase and the built
times are the row's own - a green check means **the derivation matches the built values**, not
that the lore goal is met. The goal miss is printed as a RED line and stays in this sheet
until take A3 resolves it.
