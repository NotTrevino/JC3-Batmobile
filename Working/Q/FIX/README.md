# Fix cards from in-game tests

In-game test briefs write one fix card per failed check here, named `FIX-<landmark>-<check>-<date>.md`, in the
GRAB_BACKLOG.md section 0.4 card format: In / Do / Out / Done / Stop, plus the failing observation, the screenshot or
telemetry path, and which stage the fix returns to (TRANSLATE or BUILD). Triage briefs read this folder. A failed
check is never retuned on the spot, and a band is never re-interpreted (STAGES.md, TEST row).
